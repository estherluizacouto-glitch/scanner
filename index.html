Scanner

Buscas amplas gastam menos cota e trazem mais resultados. Buscas específicas gastam mais e trazem menos, porém mais precisos. O filtro "Postou recentemente" soma +1 unidade por canal candidato.

Suas chaves da YouTube Data API

Gere uma chave gratuita no Google Cloud Console (API "YouTube Data API v3") e cole abaixo. Cada chave tem 10.000 unidades/dia. Adicione mais de uma para o Scanner alternar automaticamente quando uma esgotar. As chaves ficam salvas só no seu navegador (localStorage) — nunca são enviadas a nenhum servidor além do Google.
